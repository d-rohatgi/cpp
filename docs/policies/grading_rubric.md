# Course-Wide Grading Rubric

## Standard rubric per assignment
- 35% Correctness
- 20% Testing depth
- 15% API clarity and code quality
- 15% Benchmark rigor
- 10% design note and tradeoff analysis
- 5% build hygiene / documentation

## How strong students distinguish themselves
They do not just pass the public tests.
They:
- find failure cases the visible suite misses
- test lifetime bugs
- benchmark before and after changes
- write down invariants explicitly
- choose simpler designs when the complexity budget is tight
