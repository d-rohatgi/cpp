# Recommended Workflow

## For beginner weeks
1. read the assignment
2. get the program running
3. try examples by hand
4. add 2–3 checks
5. clean up code

## For middle weeks
1. write down invariants
2. implement a minimal version
3. run public tests
4. add your own tests
5. benchmark

## For later weeks
1. define correctness and performance targets
2. instrument the code
3. test under sanitizers
4. benchmark against a baseline
5. document tradeoffs
