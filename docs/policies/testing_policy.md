# Testing Policy

The public tests are intentionally incomplete.

They are there to:
- verify the build works
- catch obvious mistakes
- communicate the style of tests you should write

They are not there to certify correctness.

## Minimum standard for your own testing
Every assignment should include:
- normal-case tests
- edge-case tests
- failure-case tests
- randomized tests where practical
- long-run stress tests

## Strong habit
Every bug gets a regression test.
