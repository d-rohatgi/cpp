# Benchmark Policy

You are expected to measure performance, not guess at it.

## Minimum benchmark standard
For each performance-sensitive assignment:
- test at least 2 input sizes
- compare against an STL or clearly stated baseline
- record one optimization attempt
- write a short note explaining the result

## Questions your benchmark should answer
- How does runtime scale with N?
- Where do constant factors dominate?
- What tradeoff did your design make?
- Did locality or allocation behavior matter?
