# Syllabus

## Goal
Become an elite C++ programmer through a progression that matches how deep skill develops:

1. fluency
2. abstraction
3. systems rigor

## Assessment model
Each week includes:
- one implementation target
- one testing target
- one reflection target
- one concept retrieval target

## Course rule
Passing public tests is necessary, not sufficient.


## Getting started

Before Week 1:
- finish `docs/getting_started_vscode.md`
- confirm you can build the repo
- confirm you can run `ctest`
- confirm you can open and use the debugger
