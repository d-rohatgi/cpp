# Interview Study Loop

Use this exact loop for every coding problem.

## Step 1 — Clarify
- Restate the problem
- Ask clarifying questions
- Name the inputs and outputs

## Step 2 — Baseline
- Describe brute force
- State why it is too slow or too clumsy

## Step 3 — Better approach
- Name the pattern
- State the core invariant
- Explain the data structure choice

## Step 4 — Code
- Write the solution in C++
- Keep the code readable
- Prefer correctness over cleverness

## Step 5 — Test
At minimum test:
- empty or minimal input
- one normal case
- one edge case
- one case likely to break your logic

## Step 6 — Complexity
State:
- time complexity
- space complexity

## Step 7 — Postmortem
Write five lines:
- pattern
- invariant
- edge cases
- complexity
- what I missed first

## System design loop

For every design:
1. Clarify scope
2. Estimate scale
3. Define APIs
4. Define data model
5. Sketch high-level design
6. Identify bottlenecks
7. Discuss tradeoffs
8. Add reliability / observability
9. Revisit under a changed constraint

## Behavioral loop

For every story:
- situation
- goal
- actions
- reasoning
- result
- reflection

## Rule

Do not optimize for raw problem count.
Optimize for:
- clean solutions
- calm explanation
- edge-case awareness
- repeatable structure
