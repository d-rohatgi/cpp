# Behavioral Story Bank

Prepare one story for each of these themes:

- ownership
- ambiguity
- technical disagreement
- failure / bug / outage
- mentoring
- prioritization under pressure
- improving an existing system
- tradeoff decision
- stakeholder communication
- learning something difficult quickly

## Story structure
Use a clean structure:
- situation
- goal
- actions
- reasoning
- result
- reflection

## Senior bar
Senior answers should show:
- judgment
- prioritization
- cross-team awareness
- technical depth
- learning
