# Coding Interview Plan

## Problem categories
- arrays / strings
- hashing
- two pointers / sliding window
- stack / queue
- linked lists
- trees / BSTs
- heaps
- graphs
- intervals
- binary search
- backtracking
- dynamic programming

## Standard interview ritual

1. Restate the problem
2. Ask clarifying questions
3. State brute force
4. State better approach
5. Name invariant
6. Code
7. Dry-run one example
8. Name edge cases
9. State time and space complexity

## Senior bar
The interviewer is judging:
- structure
- calmness
- communication
- correctness
- testing instinct
- tradeoff awareness
