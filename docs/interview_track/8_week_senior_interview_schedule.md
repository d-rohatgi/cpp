# 8-Week Senior Interview Schedule

## How to use this schedule

This schedule is designed to run **alongside** the C++ course.  
The goal is not only to become stronger in C++, but also to become ready for senior software engineering interviews at competitive firms.

The schedule has four lanes:

1. Coding interviews
2. System design
3. Behavioral / project communication
4. Ongoing C++ engineering depth

## Weekly structure

- **Monday:** 1–2 coding problems
- **Tuesday:** 1–2 coding problems
- **Wednesday:** C++ course + 1 re-solve
- **Thursday:** 1–2 coding problems
- **Friday:** system design + behavioral
- **Saturday:** timed mock work
- **Sunday:** review and re-solve misses

# Weekly scorecard

At the end of each week, score yourself from 1–5 on:

- Coding correctness
- Coding communication
- Edge-case testing
- System design structure
- Tradeoff discussion
- Behavioral clarity
- C++ fluency

Use the score trend, not one day, to judge progress.
