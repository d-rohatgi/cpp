# System Design Track

## Stage 2 — light system design
Do one 15-minute design each week:
- URL shortener
- rate limiter
- file upload service
- metrics pipeline
- leaderboard service

## Stage 3 — full system design
Do one 35–45 minute design every 2 weeks:
- chat system
- analytics pipeline
- distributed job queue
- autocomplete service
- telemetry aggregation system
- Redis-like key-value store

## Design framework

1. Clarify scope
2. Estimate scale
3. Define APIs
4. Define data model
5. Sketch high-level architecture
6. Identify bottlenecks
7. Discuss tradeoffs
8. Add reliability and observability
9. Revisit under one changed constraint
