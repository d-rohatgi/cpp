# Course Map

## Stage 1 — Foundations Bootcamp (Weeks 1–6)
1. Calculator and control flow
2. Strings, vectors, loops, functions
3. Structs, classes, methods
4. File I/O and multi-file programs
5. STL maps and counting problems
6. Pointers, references, and linked-structure intuition

## Stage 2 — Core Data Structures and Algorithms in C++ (Weeks 7–14)
7. Dynamic vector
8. Smart pointers
9. Generic algorithms
10. Hash map
11. LRU cache
12. Trees
13. Heaps and tries
14. Graphs and shortest paths

## Stage 3 — Elite Systems C++ (Weeks 15–24)
15. Memory pools and allocators
16. Cache-efficient matrix / layout work
17. Thread pool
18. Concurrent queue
19. TCP server
20. Log-structured storage
21. B+ tree
22. Redis-style KV store
23. Query / streaming engine
24. Capstone
