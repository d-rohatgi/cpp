# Learning Science Behind the Course

## Generation
You write the code yourself.

## Retrieval
At the end of the week, answer from memory:
- what invariant mattered most?
- what bug cost the most time?
- what is the runtime of core operations?

## Desirable difficulty
Support fades over time.
Early weeks are concrete.
Later weeks require more independent design.

## Reflection
Every week should end with a short postmortem.
