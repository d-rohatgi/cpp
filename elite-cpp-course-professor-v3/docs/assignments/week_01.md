# Week 01 — Calculator and Basic Control Flow


## Objective
Build comfort with compiling, running, and reasoning through simple C++ code.

## Main assignment
Implement a calculator function and a tiny CLI wrapper.

## Contract
Your core function should:
- support +, -, *, /
- reject invalid operators
- reject division by zero

## Deliverables
- implementation
- 8 manual test cases
- short reflection
